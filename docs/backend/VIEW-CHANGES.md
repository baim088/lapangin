# Log Perubahan View (Blade Frontend)

Dokumen ini mencatat setiap perubahan pada file view di `resources/views/` agar rekan frontend (Ibrahim) dapat mereview dengan mudah.

| File | Baris | Sebelum | Sesudah | Alasan Perubahan |
|---|---|---|---|---|
| `resources/views/auth/login.blade.php` | 91, 103, 107-111, 140-144 | `action="#"`, tanpa `value="{{ old('email') }}"`, tanpa pesan error | `action="{{ route('login') }}"`, `value="{{ old('email') }}"`, `@error('email')`, `@error('password')` | Mengaktifkan form submit login, retensi input email, dan pesan validasi error Indonesia |
| `resources/views/auth/register.blade.php` | 85, 93, 103, 114, 147 | `action="#"`, input tanpa value old(), terms tanpa checked | `action="{{ route('register') }}"`, `old()` untuk name/phone/email/terms, `@error` untuk name, phone, email, password, terms | Mengaktifkan form registrasi customer baru dengan pesan error dan retensi input |
| `resources/views/components/navbar.blade.php` | 49-74, 131-155 | Hardcoded tombol Masuk dan Daftar pada desktop & mobile | Dibungkus `@guest` dan `@auth`: menampilkan nama user, link dashboard sesuai role (Customer/Operator/Admin), dan tombol Keluar (POST logout) | Menyesuaikan navigasi autentikasi dinamis sesuai status sesi dan peran pengguna |
| `resources/views/lapangan.blade.php` | 45, 90-394 | 4 kartu lapangan hardcoded statis | Menggunakan `@forelse ($courts as $court)` dari database, matriks harga dinamis, spesifikasi dinamis, dan link ke `route('lapangan.detail', $court->slug)` | Menampilkan seluruh katalog lapangan riil dari database (futsal, badminton, mini soccer, padel) |
| `resources/views/lapangan-detail.blade.php` | 28, 48-62, 69-92, 120-205, 323, 485-520 | Nama dan spesifikasi statis Futsal Arena A, 15 baris slot dummy statis | Menampilkan data lapangan dinamis dari model `$court`, slot per jam dinamis berdasarkan jam operasional venue, integrasi AJAX tanggal ke endpoint `/api/lapangan/{slug}/slots`, dan state slot (terisi/blokir/maintenance/lewat/tersedia) | Menyediakan jadwal riil per lapangan dan tanggal dengan deteksi ketersediaan akurat |
| `resources/views/welcome.blade.php` | 1098, 1106-1145, 1242-1250 | Alpine state dummy untuk sportCatalog, tanggal statis 3 Nov | Data sportCatalog diambil dari harga lapangan di database, opsi tanggal dinamis 7 hari ke depan, navigasi checkout dinamis berdasarkan slug lapangan | Mengintegrasikan widget reservasi cepat di beranda dengan database |
| `resources/views/booking/checkout.blade.php` | 19-215 | Data lapangan hardcoded, form checkout tidak memiliki action/method/@csrf, input tanpa name | Form action ke `route('booking.checkout.store', $slug)`, input hidden untuk booking_date dan slots[], data pemesan otomatis terisi data user login, rincian slot dan harga dihitung per jam (mendukung jam non-berurutan) | Menghubungkan proses checkout dengan backend BookingService::createPending |
| `resources/views/booking/konfirmasi.blade.php` | 19-180 | Data booking statis dummy, form upload bukti tanpa multipart, countdown hardcoded | Menampilkan data booking riil ($booking->booking_code, ringkasan jam, harga), form multipart POST ke `route('booking.upload-proof', $booking->id)`, countdown tersinkronisasi dari expires_at server | Mengaktifkan alur pembayaran manual dan pengunggahan bukti transfer tepat waktu |
| `resources/views/booking/sukses.blade.php` | 18-95 | Kode booking statis LPN-2026-4729 dan QR statis | Menampilkan booking_code dinamis, detail jadwal riil, dan checkin_token sebagai teks plain untuk check-in | Menyajikan e-tiket resmi dari booking yang telah tersimpan |
| `resources/views/user/dashboard.blade.php` | 22-55, 76-235, 299-315 | Statistik statis (12, 11, 1, Rp 1,4 Jt), array dummy upcoming/history/cancelled, reminder statis | Statistik dihitung dari query database ($totalBookings, $successfulBookings, $cancelledBookings, $totalSpent), looping data booking riil per tab, aksi bayar sekarang dan pembatalan booking pending, reminder jadwal terdekat | Mengintegrasikan dashboard akun penyewa dengan data booking riil |
| `resources/views/user/booking-detail.blade.php` | 22, 28-63, 118, 128-148 | Detail pemesanan statis, kode booking dummy LPN-2026-4729, QR statis tanpa teks token, tombol aksi statis | Banner status dinamis (pending/confirmed/done/cancelled), rincian jadwal riil, checkin_token ditampilkan sebagai teks, aksi pembatalan untuk booking pending dan tombol bayar sekarang | Menampilkan halaman detail booking lengkap dan e-tiket penyewa |
